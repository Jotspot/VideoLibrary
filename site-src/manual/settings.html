Open Settings with ⌘, or the gear button in the toolbar.

General
Player options (full screen, fit window to video, miniplayer) and your libraries, with Import Videos and Add Library Folder….
Captions
Caption presets, style, position and motion, with a live preview. See Captions.
Downloads
Default resolution and quality, the YouTube sign-in and the Nebula sign-in.
Suggestions
Feed source and type, which library downloads go to, Hide Shorts and the minimum length, and the Google Cloud API option.
Music
Turn music on, choose one collection or one per library, and hide the music bar when leaving Music.
Tools
Versions of yt-dlp, FFmpeg and Deno with Install & Update All and Check Again, and the experimental SABR Add-on.
Privacy
How your data is stored, and Run Security Check, which looks for any plaintext secrets left by older versions and encrypts them.
Help
Player shortcuts, a link to this manual, and the debug log (Open Debug Log, Show in Finder, Clear Log).

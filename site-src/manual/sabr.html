YouTube is moving to a new way of streaming video called SABR. For some accounts and some networks (VPNs and datacenter connections in particular), YouTube offers HD only as SABR streams, and the standard download tools can't save those yet. Without help, those downloads come out in 360p.

VideoLibrary handles this in steps:

  1. It notices SABR as soon as yt-dlp picks a format, before anything downloads.
  2. It tries other YouTube clients that often still get regular HD streams: Safari's, then the TV app's. The downloads panel shows "Getting the HD version…". Signed-in downloads start with Safari's client anyway, so this step is usually skipped.
  3. If the SABR add-on is installed, it downloads the video in HD with that.
  4. If none of that works, it saves the 360p version and keeps the download in the panel with an Install SABR Add-on & Retry button.

The SABR add-on

The add-on is a preview build of yt-dlp with SABR support (yt-dlp pull request #13515). It's experimental, so it's never installed up front:

  • A download offers it when it's needed, as above.
  • You can also install it from Settings › Tools › Experimental. Because it's preview software, you'll be asked several times to confirm.
  • It's about 37 MB, checked against its published checksum when installed, and kept in Application Support. It never replaces your Homebrew yt-dlp, and it's only used for videos limited to SABR.
  • Settings › Tools can update or remove it. brew upgrade doesn't update it.

Already have 360p videos? Library cards flag them, and a banner offers Re-download in HD.
